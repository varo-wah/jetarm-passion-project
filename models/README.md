# Models

Store YOLO weights and exported model artifacts here.

- `pretrained/`: base YOLO weights such as `yolo11n.pt`, `yolo11s.pt`, and `yolov8n.pt`
- `trained/`: project-trained weights such as `best.pt`
- `exported/`: exported formats such as ONNX or TensorRT engine files

Large model files should usually stay out of Git unless they are intentionally tracked.
